RESEARCH PROJECT

About MIMII Industrial AI

Annotation-efficient industrial machine fault detection using deep learning and an agentic active-learning framework.

ACADEMIC RESEARCH

Project Objective

To detect abnormal industrial machine sounds using a CNN-LSTM model and investigate how active learning can reduce the amount of labelled data required for model training.

Dataset Information

The project uses the MIMII Sound Dataset, containing normal and anomalous industrial machine sounds.

Machine categories Valve, Pump, Fan, Slide Rail
Dataset classes Normal and Abnormal
Audio format WAV
Model CNN-LSTM

Agentic Active Learning Workflow

01 Training Agent Trains CNN-LSTM
02 Selection Agent Selects uncertain samples
03 Annotation Agent Reveals selected labels
04 Evaluation Agent Checks validation F1
